# Getting started

*Install it, then give each character one quick visit so Alt Inventory can see what they hold.*

Alt Inventory adds a few lines to an item's tooltip: which of your characters hold that item, and where. It also keeps every character's gold, their currencies and how long you've played each one.

### Install

1. **CurseForge app:** search for **Alt Inventory** and click Install.
2. **By hand:** download it from [CurseForge](https://www.curseforge.com/wow/addons/alt-inventory-tracker) and put the **AltInventory** folder in `World of Warcraft\_retail_\Interface\AddOns`.
3. Start the game, or type `/reload` if it's already running.

### Visit each character once

The game only lets an addon see the character you're logged in on. So Alt Inventory learns about each character when you play it:

1. **Log in on each character once** with the addon installed. That records its bags, gold, currencies and play time.
2. **Open the bank** on that character once, and the **Warband Bank** once.
3. **Open the mailbox** once, so items waiting in the mail are counted too.

That's all. From then on every character sees every other character's items, and the counts update each time you play them.

> Altoholic, DataStore and TradeSkillMaster work the same way, for the same reason: the game doesn't share another character's bags.

### Where to find it

- **Tooltips:** hover any item. See [Item tooltips](Item-tooltips.md).
- **The window:** click the Alt Inventory button on the minimap, the magnifier in your bags' search box, or type `/altinv search`. See [Searching your characters](Searching-your-characters.md).
